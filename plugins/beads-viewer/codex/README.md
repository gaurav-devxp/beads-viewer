# Codex plugin

Place Codex-specific plugin files here. Shared application and package paths are relative to the monorepo root, three directories above this directory. The plugin runtime has not been scaffolded yet.

The confirmed distribution direction requires authenticated Codex, supported Node.js
and an existing working Beads installation, with prebuilt application/MCP assets in
the plugin. The runtime correction is implemented for Claude; see the
[portable runtime policy](../../../docs/claude-code/PORTABLE_RUNTIME.md).
This directory is still a scaffold, not an
installable Codex plugin.
